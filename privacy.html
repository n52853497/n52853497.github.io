Datenschutzerklärung

Live Clipper ist ein privates Werkzeug des Betreibers. Es wird nur mit dem eigenen Google-/YouTube-Konto des Betreibers verwendet.

Welche Google-Daten werden genutzt?

Die App fordert den Zugriff https://www.googleapis.com/auth/youtube an. Sie nutzt ihn ausschließlich, um Videos auf den verbundenen YouTube-Kanal hochzuladen, deren Titel und Beschreibung zu setzen und den Verarbeitungsstatus hochgeladener Videos abzufragen.

Speicherung

Zugriffs- und Aktualisierungstoken werden ausschließlich lokal auf dem Server des Betreibers gespeichert (Datei mit Zugriffsrechten nur für den Betreiber). Sie werden nicht an Dritte übermittelt.

Weitergabe

Es erfolgt keine Weitergabe, kein Verkauf und keine Nutzung von Google-Nutzerdaten zu Werbezwecken oder zum Training von KI-Modellen. Die Nutzung von Informationen, die über Google-APIs bezogen werden, entspricht der Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen.

Löschung

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden; lokale Token werden dann ungültig und können gelöscht werden.

Privacy Policy

Live Clipper is a private tool used only with the operator's own Google/YouTube account. It requests the https://www.googleapis.com/auth/youtube scope solely to upload videos to the connected YouTube channel, set their title and description, and read the processing status of uploaded videos.

Access and refresh tokens are stored only locally on the operator's server and are never shared with third parties. Google user data is not sold, not used for advertising and not used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions. Contact: github.com/n52853497
